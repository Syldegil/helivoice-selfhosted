# Limitations

Experimental. Historical transport protection depended on local network/firewall assumptions; it is not a portable guarantee. This export requires HTTPS client transport, explicit token provisioning and controlled Wyoming transport. Python's HTTP server is not a hardened public edge server; use the specified proxy boundary and resource limits.

Cancellation during an in-flight request does not necessarily disconnect the HTTP request; a late response may target the current input field. This remains an unresolved client lifecycle limitation. Audio buffers are in memory in the inspected path; no explicit secure erasure is implemented. Server/STT/proxy configuration determines retention. No complete recent end-to-end, interrupted-network, lifecycle, accessibility or endurance qualification is claimed. HeliBoard integration depends on its configured voice-input behavior; no HeliBoard code is included.
