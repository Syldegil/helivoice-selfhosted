# Privacy and network flows

Microphone PCM is uploaded as WAV to the configured HTTPS server; the gateway forwards audio to the configured Wyoming backend and returns text. A single preceding editor character is read locally only for spacing. There is no analytics/pixel/added telemetry. Build/bootstrap and pip contact public dependency hosts. The token is held via Android Keystore AES/GCM; no existing key or token is exported.

No private endpoint, namespace, voice, transcript, household equipment, user path, account or signing identity is retained. example.org and loopback values are fictional/configuration examples. Gateway request logging is disabled; reverse proxy and STT logging must be configured separately. Audio is not inherently offline or guaranteed unretained by an arbitrary chosen server. GitHub association with Syldegil does not guarantee anonymity.

Stored credentials are bound to their normalized endpoint; an endpoint mismatch makes loadToken return no credential. Input validation occurs before configuration mutation.
