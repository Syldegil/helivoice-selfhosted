# helivoice-selfhosted

Experimental Android voice input client and a minimal authenticated bridge to a user-selected Wyoming speech-to-text server. Audio is sent to that server; this is not fully offline transcription.

Experimental sources maintained by Syldegil. [Français](README.fr.md).
